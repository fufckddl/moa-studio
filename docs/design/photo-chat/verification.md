# 대화형 사진 수정 패널 검증

운영: https://moa-studio.pages.dev

## 구현 및 확인

- 우측 AI와 수정하기 버튼으로 슬라이드 패널 열기. 기존 문구·사진·레이아웃 수정 도구 유지.
- 선택한 카드 및 원본 사진 표시, 요청 예시 선택, 2,000자 요청 입력.
- 패널 닫기/재열기 시 요청 초안 유지, Escape로 닫기.
- 데스크톱 패널 옆에서 기존 편집 도구 사용 가능. 모바일 패널은 화면 전체 폭 사용.
- 공개 사이트에서 패널 열기·닫기·초안 유지·연결 상태 확인. 390px 모바일에서 content width=viewport width=390.
- 변경안 비교·적용·버리기·한 단계 되돌리기 구현. 적용 시 별도 사진 ID를 사용해 저장된 원본 객체를 덮어쓰지 않음.
- 같은 사진을 쓰는 카드들의 참조 갱신, 다른 사진·수동 문구 유지, 오래된 변경안 거절을 실제 앱에서 쓰는 함수의 단위 테스트로 확인.
- Node 테스트 48개, Edge Function 테스트 7개 통과. 타입 검사·빌드·클라우드 비밀키 검사 통과.

## 실제 AI 연결 상태

실제 사진 편집 모델/API는 연결하지 않았다. 앞서 사용자가 AI 연결을 보류했고, 이번 작업에서 재개할지 질문한 상태다.
공개 상태 API는 imageEditingConfigured=false를 반환한다. 로그인한 /edit도 공급자 미연결 상태에서 503을 반환하며 AI 호출이나 사용량 차감을 하지 않는다.
따라서 실제 AI 응답으로 변경안 생성 → 적용 → 저장 → 다운로드하는 전체 흐름은 아직 검증할 수 없다. UI·API 계약·적용/복원 로직 구현과 실제 제공자 연동 완료는 구분한다.

파일: desktop.png, mobile.png는 공개 사이트 검사 화면.
