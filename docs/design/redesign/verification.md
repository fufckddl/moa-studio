# 메인 페이지와 편집기 개편 검증

2026-09-06. 기본 진입을 사진 중심 메인 페이지로 변경하고 스크롤 소개와 편집기를 연결했습니다.

## 기능

- 홈 첫 화면에 입력 폼 없음. 사진 2개 정상 로드.
- 모아 이야기 → 소개 섹션, 콘텐츠 안내 링크 → 과정 섹션 이동 확인.
- 상단 스튜디오 열기와 하단 스튜디오 시작하기 모두 편집기로 진입.
- 메뉴 이름을 변경한 후 홈 왕복 및 보관함에서 브라우저 뒤로가기: 입력값 유지.
- 새 배치에서 생성 버튼 실행: 입력 메뉴가 카드와 게시글에 반영됨.
- 편집기 직접 주소 새로고침 정상. 템플릿 생성 API 정상.
- 390×844 모바일 홈/편집기 문서 너비 390px. 모바일 입력 영역이 미리보기보다 먼저 표시됨.
- 1536×1024 데스크톱 미리보기 x=36, 입력 x=925.6. 생성 버튼 하단 y=967.5로 초기 화면 내 표시.
- npm run build: TypeScript와 Vite 빌드 통과. npm test: 기존 서버 테스트 10개 통과. 별도 lint 설정 없음.

이전 내장 브라우저 확인창 정지 이력이 있어 Chrome에서 검증했습니다. 개발 서버가 중간에 종료된 것을 확인해 재시작한 후 이미지 로딩, 라우팅, 생성 및 화면을 다시 검증했습니다.

## 시각 비교

각 컨셉과 실제 브라우저 캡처를 열어 직접 비교했습니다.

1. 첫 화면의 전체 사진, 큰 한국어 세리프, 로고와 텍스트 링크 배치를 구현했습니다. 설명은 제목 아래에 배치하여 읽는 순서를 정리했습니다.
2. 이야기 섹션의 비대칭 사진/글 구성, 넓은 여백과 밝은 배경을 구현했습니다. 실제 프로젝트의 라떼 사진을 사용했습니다.
3. 과정은 카드 박스 없이 세 개의 가는 선과 번호로 구분하고 녹색 시작 영역으로 이어집니다.
4. 편집기는 상단 내비게이션, 왼쪽 미리보기와 오른쪽 입력, 제목 옆 저장, 결과 위 PNG/ZIP 배치로 변경했습니다. 컨셉이 임의로 생성한 입력값은 기존 실제 기능에 맞췄습니다.
5. 모바일에서 사진 크롭을 조정하고 제목 영역의 명암을 보강했습니다. 스크롤 진입 모션은 reduced-motion 설정에서 비활성화됩니다.

사용자 요구와 핵심 시각 방향을 충족하며 원본 컨셉의 픽셀 단위 복제는 아닙니다. `hero-desktop.png`, `hero-mobile.png`, `home-desktop-full.png`, `home-mobile-full.png`, `editor-desktop.png`, `editor-mobile.png`는 실제 브라우저 캡처입니다.

## 자산 생성

내장 Image Gen 사용. 컨셉 4종과 텍스트 없는 히어로 사진 1종을 생성했습니다. 프롬프트 핵심은 ‘절제된 에디토리얼 한국어 카페 콘텐츠 서비스, Noto Serif KR, 따뜻한 흰색과 포레스트 그린, 첫 화면 사진과 문구만, 이어지는 이야기·과정·시작, 사이드바 없는 편집기’입니다. 히어로 자산은 `public/assets/cafe-hero.png`, 컨셉은 이 폴더의 `*-concept.png`에 보관합니다.

저장·내보내기와 템플릿 생성의 기존 구현은 유지합니다. 공개 배포나 실제 AI 연결은 이번 변경 범위에 포함하지 않습니다.
