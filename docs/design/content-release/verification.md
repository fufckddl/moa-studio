# 공개 편집 기능 검증

검증일: 2026-09-06. 공개 주소: https://moa-studio.pages.dev

## 확인 결과

- Node 테스트 41개, Deno Edge Function 테스트 6개 통과
- TypeScript 검사, production build, 클라우드 코드 검사 통과
- 원격 SQL 테스트를 트랜잭션 rollback으로 실행: AI 사용량 변경 권한, 브랜드 수 제한, 월별 이용 기간, 예약 만료 검증
- 공개 API: 상태 조회 200/template/configured=false, 비로그인 권한 조회 401, 로그인 무료 계정 권한 및 템플릿 생성 200
- 공개 편집기: 포스터 레이아웃, 제목·본문·가운데 정렬, 카드 4장, 선택한 날짜의 일정 저장 후 원격 데이터 일치 확인
- 무료 계정의 두 번째 브랜드 저장은 서버에서 400으로 거절
- PNG 실제 다운로드 후 이미지 검사: 1080×1350, 편집한 제목·본문·사진 반영
- ZIP 실제 다운로드 후 압축 내용 검사: 1080×1350 PNG 4장, caption.txt, schedule.txt 포함
- 390×844 모바일에서 documentElement.scrollWidth=390 확인, 가로 넘침 없음

- editor-mobile.png: 공개 편집기 모바일 캡처

## 남은 검증과 운영 상태

- 토스 공개 테스트 결제창에서 카드 선택 완료. 필수 약관 동의에 대한 사용자 응답 대기 중이며 최종 승인은 수행하지 않음
- 최종 승인·공개 콜백·승인된 테스트 주문 내역은 아직 미검증
- 해당 단계 재개를 위한 임시 QA 계정과 미승인 테스트 주문을 유지. 완료 후 해당 계정만 정리해야 함
- 실제 AI 연동은 사용자 요청으로 이번 작업에서 제외. 현재 결과는 템플릿 생성이며 AI 품질을 검증한 결과가 아님
- 실결제 비활성. 테스트 결제로 유료 권한을 부여하지 않음
- 유료 플랜의 제한은 자동/SQL 테스트로 확인했으며 실제 유료 고객 결제로 검증한 것은 아님
- Vite 빌드의 약 516KB 번들 크기 경고는 남아 있음
