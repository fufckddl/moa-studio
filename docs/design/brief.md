# 모아 스튜디오 — 구현 기준

대상: 카페 운영자. 사진과 메뉴 정보에서 카드뉴스 3장, 게시글, 주간 게시 계획을 만든다.
디자인 기준: `concept.png`. 생성된 디자인에 근거한 실제 편집 도구이며 랜딩 페이지가 아니다.

- 데스크톱 왼쪽 220px 사이드바, 상단 76px 저장 바, 2열 작업 공간.
- 브랜드: `mo:a studio`, 내비게이션 콘텐츠 만들기 / 보관함 / 브랜드 설정.
- 제목: 사진 한 장, 일주일의 콘텐츠.
- 배경 #f8f7f3, 사이드바 #fff, 잉크 #262c28, 포레스트 #254a3b, 경계 #dedfd8.
- UI Noto Sans KR / DM Sans, 주요 제목·카드 타이포그래피 Noto Serif KR.
- 폼 폭 330~360px, 미리보기 4:5, 화면 너비에 따라 자연스럽게 축소.
- 미리보기 영역 카드뉴스 / 게시글 / 주간 일정 탭, 내보내기.
- 모바일은 내비게이션 가로형·폼/미리보기 세로 배치. 모든 CTA 접근 가능.
- 필요한 상태: 사진 추가/삭제/선택, 생성중/실패, 3장 전환·문구 편집,
  게시글 수정·복사, 계획 보기, 브랜드 저장, 프로젝트 저장/불러오기/삭제,
  PNG 및 ZIP 다운로드.
- 정직한 상태 표기: API 연결 시 AI 생성, 키 없을 때 템플릿 모드.
  템플릿은 사용자가 입력한 사실만 반영. 가상의 할인/효능/리뷰 생성 금지.
- 의도적 조정: 예시사진은 생성한 라떼 사진 1장으로 시작. 불필요한 드래그 정렬 문구 생략.
  가격·콘텐츠 목적·문구 편집은 실제 사용에 필요한 필드로 추가.
