# 모아 스튜디오 검증 기록

2026-09-06 · 사용자 선택에 따라 템플릿 모드로 전달합니다.

## 실행 및 기능 검증

- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과, 38개 모듈.
- `npm test`: 서버 테스트 10개 통과. 입력 검증, 용량 제한, 가격 표기, 이미지 연결, 말투·목적 조합, 공급자 오류 처리를 포함합니다.
- 로컬 API 상태는 `configured: false`, `mode: template`. 실제 생성 요청 200, 카드 3장과 게시 계획 3건을 확인했습니다.
- 브라우저에서 메뉴·설명·말투 변경 후 생성, 게시글 복사, 주간 일정, 카드 문구·레이아웃 편집을 확인했습니다.
- 사진 업로드 및 JPEG 변환, 지원하지 않는 파일의 오류 안내를 확인했습니다.
- 저장 후 새로고침, 보관함에서 열기, 브랜드 설정 복원을 확인했습니다.
- Chrome에서 삭제 대화상자 취소와 확정, 빈 보관함으로 전환을 확인했습니다. 내장 브라우저의 네이티브 확인창 정지 문제를 앱 내부 HTML 대화상자로 수정했습니다.
- 실제 PNG 다운로드 크기는 1080×1350입니다. ZIP CRC 검사 통과, 카드 PNG 3개와 `caption.txt`, `schedule.txt`를 확인했습니다.
- 모바일 390×844에서 문서 너비 390px로 가로 넘침이 없습니다. 최종 전체 화면은 `mobile.png`에 저장했습니다.

## 최종 디자인 비교

`concept.png`와 실제 `desktop.png`를 동일한 1506×1045 크기로 열어 비교했습니다.

1. **구조:** 왼쪽 탐색, 상단 저장, 입력 패널과 큰 카드 미리보기의 구조를 유지했습니다. 실제 입력 항목을 수용하도록 사이드바와 입력 패널 폭은 조정했습니다.
2. **색상:** 크림색 배경, 흰색 패널, 짙은 녹색 선택 상태와 생성 버튼을 유지했습니다. 경계선과 그림자는 약하게 사용했습니다.
3. **서체:** 한국어 세리프 제목과 읽기 쉬운 산세리프 입력 UI를 유지했습니다. 다운로드 카드의 제목은 긴 문구도 들어가도록 자동 크기를 적용해 컨셉보다 작습니다.
4. **사진과 결과:** 별도로 생성한 카페 사진을 실제 이미지 자산으로 사용합니다. 기본 예시는 한 장이며 사용자는 최대 세 장을 업로드할 수 있습니다. 컨셉의 사진 구성과는 의도적으로 다릅니다.
5. **작동하는 컨트롤:** PNG·ZIP 직접 다운로드, 가격·목적 입력, 문구 편집, 템플릿 모드 안내를 추가했습니다. 컨셉에 표시된 썸네일 드래그 정렬은 구현 범위에 포함하지 않고 카드 선택 버튼으로 제공했습니다.

판정: 핵심 시각 방향과 사용 흐름 충족. 픽셀 단위 복제는 아니며 실제 편집·내보내기 기능을 위한 차이가 있습니다. 데스크톱에서는 생성 버튼이 초기 화면에 보이고 모바일에서는 입력 뒤 미리보기로 이어집니다.

## 검증 범위와 제한

OpenAI 키 생성·저장은 진행하지 않았으며 실제 AI 공급자 호출은 검증하지 않았습니다. 로그인, 동기화, SNS 자동 게시, 결제, 공개 서버 배포는 포함하지 않습니다. 저장 데이터는 사용하는 브라우저에 한정됩니다. 별도 lint 설정은 없으며 TypeScript와 빌드, 서버 테스트, 브라우저 수동 검증을 사용했습니다.
