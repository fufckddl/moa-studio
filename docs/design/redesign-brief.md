# 모아 스튜디오 진입 화면 개편

사용자 요구: 이름과 폰트 유지. 첫 화면은 사진과 텍스트 중심. 스크롤하면 서비스 정보를 보여주고 편집기로 연결. 레이아웃과 버튼 위치 전반 수정.

## 디자인 기준

- 첫 화면: 전체 카페 사진, 큰 세리프 제목과 짧은 설명. 상단 로고와 텍스트 링크, 하단 스크롤 안내.
- 이야기: #f6f3ed 바탕, 왼쪽 서비스 설명과 오른쪽 세로 사진. 카드 테두리 없이 넓은 여백.
- 사용 흐름: 가는 선으로 구분한 3단계. 현재 템플릿 모드 안내.
- 시작 영역: #233c30 녹색 바탕, 큰 제목과 시작 버튼. 간결한 푸터.
- 편집기: 사이드바를 상단 메뉴로 변경. 미리보기 왼쪽, 입력 오른쪽. 저장은 제목 옆, PNG/ZIP은 결과 위, 생성은 입력 끝.
- 글꼴: Noto Serif KR, Noto Sans KR, DM Sans 유지.
- 모바일: 작은 뷰포트 기준 높이, 세로 순서. 편집기는 입력 후 결과. 키보드 포커스와 reduced-motion 지원.
- 내비게이션: 기본 홈, #/studio 편집기, #/studio/library 보관함, #/studio/brand 브랜드. 홈 섹션 앵커와 뒤로가기 지원. 동일 세션 홈 왕복 시 편집 내용 유지.
