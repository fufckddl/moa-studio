# 참고 사진과 플랜별 AI 사진 채팅

## 사용 흐름

우측 `AI와 수정하기` 패널에서 참고 이미지를 최대 3장 첨부한다.
현재 카드 사진 1장과 참고 사진 최대 3장을 한 요청에 함께 전달한다.
참고 사진마다 용도를 선택할 수 있다.

- 분위기 참고: 배경, 조명, 색감과 구도를 참고한다.
- 사진 속 제품 사용: 사용자가 지시한 제품/피사체 변경에 참고 사진을 사용한다.

파일 형식은 JPG/PNG/WEBP, 파일당 최대 10MB다. 전송용 사본을 1024px 이하
JPEG로 변환하며 실제 카드 원본을 축소하지 않는다. 첨부 순서와 용도를 모델의
이미지 번호에 명시한다. 결과는 원본과 비교한 뒤 적용하거나 버릴 수 있다.
대화 중 첨부 사진을 유지하며 삭제와 용도 변경을 지원한다.

## 채팅 횟수

| 플랜 | AI 사진 채팅 한도 | 초기화 |
| --- | --- | --- |
| 무료 체험 | 가입 후 총 3회 | 자동 초기화 없음 |
| 라이트 · 월 3,900원 | 월 10회 | 실제 이용권 시작일 기준 월별 기간 |
| 스탠다드 · 월 7,900원 | 월 30회 | 실제 이용권 시작일 기준 월별 기간 |
| 프로 · 월 12,900원 | 월 50회 | 실제 이용권 시작일 기준 월별 기간 |

기존 AI 콘텐츠 생성량과 **별도로** 계산한다. 참고 사진 수와 관계없이
결과 생성 요청 1건을 1회로 계산한다. 모델 호출 실패는 사용자 횟수를 환원한다.
결과를 버리거나 다운로드하지 않아도 생성에 성공했다면 사용 횟수에 포함된다.
테스트 결제는 유료 권한을 부여하지 않는다. 현재 실결제 활성화 정책은 변경하지 않는다.

## 서버 검증과 동시 요청

Supabase의 사용자 인증 및 RLS가 적용된 `current_moa_ai_entitlement` RPC로
실결제 플랜과 월별 기간을 조회한다. 유료 결과라면 기존 결제 서버를 통해
취소 상태를 동기화한 뒤 권한을 다시 조회한다. 클라이언트가 보낸 플랜/한도는
사용하지 않는다. 권한 조회가 실패하면 생성하지 않는다.

하나의 SQLite Durable Object에서 조회와 예약을 동기적으로 수행한다.
새 사용량 조회 API는 `GET /usage`이며 인증이 필요하다. 응답에는 플랜,
전체 한도, 사용 횟수, 남은 횟수, 적용 기간과 서비스 제공 잔량을 포함한다.
화면은 패널을 열 때와 생성 요청이 끝날 때 서버의 값을 다시 불러온다.

기존 무료 사용량 기록은 `created_at` 필드를 추가하면서 보존한다.
과거 일별 기록의 시각은 해당 UTC 날짜의 자정으로 채운다. 월별 사용량이
초기화되지 않도록 기록 보관 기간을 62일로 확대한다.

## 공급자 비용과 서비스 한도

서비스 전체 호출은 하루 50회로 제한한다. 현재 공급자는 OpenAI GPT Image 2이며,
1024×1024 Medium 결과 1장을 생성한다. OpenAI API의 입력·출력 비용이 발생한다.
Cloudflare 무료 AI 제공량과는 별개다. 실패한 모델 호출도 실제 과금 여부가
불확실하므로 서비스 전체 50회에는 포함한다. 자동 재시도는 하지 않는다.
