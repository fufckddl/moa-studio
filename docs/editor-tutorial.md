# 콘텐츠 만들기 사용법 안내

`/studio`에 들어오면 기능별 안내가 자동으로 열린다. 사진 선택, 콘텐츠 정보,
콘텐츠 만들기, 미리보기, 카드 관리, 문구·스타일 편집, AI 사진 수정,
내보내기, 작업 공간 이동을 설명한다. 편집 패널 안의 레이아웃·사진·문구·
색상·글자 크기·정렬과 AI 패널의 탭·참고 이미지·요청·실행·결과도
각각 안내한다. 현재 화면에 존재하는 기능만 순서대로 표시한다. 설명하는 영역만 선명하게 남기고
나머지 화면에는 흐림 효과와 어두운 배경을 적용한다. 강조 테두리와
흐림에서 제외하는 영역 모두 모서리가 둥근 사각형이다.
안내창은 데스크톱에서 왼쪽 아래, 좁은 화면에서는 하단에 고정한다.
단계가 바뀌어도 창과 다음 버튼의 위치·크기는 유지하고 강조 영역만 이동한다.
설명이 길면 본문만 스크롤하며, 화면 크기가 바뀔 때만 고정 영역을 다시 계산한다.

## 표시 규칙

- `완료`, `이번만 닫기`, Escape: 현재 안내만 닫는다. 다음 진입에 다시 표시한다.
- `그만 보기`: 해당 브라우저의 사용자별 설정을 저장하여 자동 표시를 끈다.
- `사용법 보기`: 자동 표시를 껐더라도 안내를 처음부터 다시 연다.
- 수동 재실행은 기존의 자동 표시 끄기 설정을 해제하지 않는다.
- 로그인·결제·확인 대화상자가 열리면 안내를 잠시 숨긴다.
- 문구 편집 단계에 도달하면 편집 패널을 열어 내부 필드까지 안내한다.
- AI 안내 단계에는 패널을 열고, 해당 단계를 벗어나거나 안내를 닫으면
  AI 패널의 원래 열림 상태로 복원한다.
- 참고 이미지와 결과 적용 등 현재 존재하지 않는 기능은 건너뛴다.
- 안내는 입력값을 바꾸거나 AI 생성·수정 요청을 실행하지 않는다.

표시 설정은 `localStorage`의 `moa:editor-tutorial:<userId|guest>:dismissed`에
저장한다. 다른 브라우저나 기기로 동기화하지 않는다. 브라우저 데이터를
지우면 안내가 다시 나타난다. 저장소를 사용할 수 없는 환경에서는 현재
안내 닫기는 가능하지만 다음 방문의 숨김 설정은 보존되지 않을 수 있다.

## 회귀 확인

1. 새 브라우저 저장소에서 `/studio` 진입 → 첫 단계 자동 표시.
2. 다음/이전으로 각 기능 설명과 강조 영역을 확인한다.
3. 마지막 단계 완료 후 새로고침 → 첫 단계 자동 표시.
4. 이번만 닫기 또는 Escape 후 새로고침 → 첫 단계 자동 표시.
5. 그만 보기 후 새로고침 또는 보관함 왕복 → 안내 자동 표시 없음.
6. 사용법 보기 → 첫 단계 표시. 닫고 새로고침 → 자동 표시 없음.
7. 데스크톱과 모바일에서 안내창이 화면 밖으로 나가지 않고 강조 영역을
   가리지 않는지, 키보드 Tab/Shift+Tab이 안내창 안에 머무는지 확인한다.
8. 안내를 닫은 뒤 사용법 보기 및 기존 편집·메뉴 버튼에 접근할 수 있는지
   확인한다. 튜토리얼 동작으로 생성 API를 호출하지 않는다.

9. 문구 편집을 닫은 뒤 안내를 실행 → 편집 단계에서 자동으로 열리고
   내부 설정이 각각 강조되는지 확인한다.
10. AI 패널을 닫은 상태와 연 상태 모두에서 안내를 실행하고, 종료 후
    원래 열림 상태가 유지되는지 확인한다.
11. 짧은 가로 화면, 태블릿, 넓은 데스크톱 및 안내 중 화면 크기 변경을
    확인한다. 긴 설명은 안내창 내부에서 스크롤할 수 있어야 한다.

12. 모든 단계를 넘길 때 안내창과 다음/완료 버튼의 좌표·크기가 동일한지
    확인한다. 좁은 화면 AI 패널은 안내창 위에 표시되고 내부에서 스크롤한다.
