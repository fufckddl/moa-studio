# 콘텐츠 만들기 사용법 안내

`/studio`에 들어오면 9단계 안내가 자동으로 열린다. 사진 선택, 콘텐츠 정보,
콘텐츠 만들기, 미리보기, 카드 관리, 문구·스타일 편집, AI 사진 수정,
내보내기, 작업 공간 이동을 설명한다. 설명하는 영역만 선명하게 남기고
나머지 화면에는 흐림 효과와 어두운 배경을 적용한다.

## 표시 규칙

- `완료`, `이번만 닫기`, Escape: 현재 안내만 닫는다. 다음 진입에 다시 표시한다.
- `그만 보기`: 해당 브라우저의 사용자별 설정을 저장하여 자동 표시를 끈다.
- `사용법 보기`: 자동 표시를 껐더라도 안내를 처음부터 다시 연다.
- 수동 재실행은 기존의 자동 표시 끄기 설정을 해제하지 않는다.
- 로그인·결제·확인 대화상자가 열리면 안내를 잠시 숨긴다.
- 현재 탭에서 존재하지 않는 기능은 안내 중 건너뛴다.

표시 설정은 `localStorage`의 `moa:editor-tutorial:<userId|guest>:dismissed`에
저장한다. 다른 브라우저나 기기로 동기화하지 않는다. 브라우저 데이터를
지우면 안내가 다시 나타난다. 저장소를 사용할 수 없는 환경에서는 현재
안내 닫기는 가능하지만 다음 방문의 숨김 설정은 보존되지 않을 수 있다.

## 회귀 확인

1. 새 브라우저 저장소에서 `/studio` 진입 → 첫 단계 자동 표시.
2. 다음/이전으로 각 기능 설명과 강조 영역을 확인한다.
3. 마지막 단계 완료 후 새로고침 → 첫 단계 자동 표시.
4. 이번만 닫기 또는 Escape 후 새로고침 → 첫 단계 자동 표시.
5. 그만 보기 후 새로고침 또는 보관함 왕복 → 안내 자동 표시 없음.
6. 사용법 보기 → 첫 단계 표시. 닫고 새로고침 → 자동 표시 없음.
7. 데스크톱과 모바일에서 안내창이 화면 밖으로 나가지 않고 강조 영역을
   가리지 않는지, 키보드 Tab/Shift+Tab이 안내창 안에 머무는지 확인한다.
8. 안내를 닫은 뒤 사용법 보기 및 기존 편집·메뉴 버튼에 접근할 수 있는지
   확인한다. 튜토리얼 동작으로 생성 API를 호출하지 않는다.
