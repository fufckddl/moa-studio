# AI 사진 대화 자동 저장

- AI 탭의 A/I를 간격 없는 세로 스택으로 배치한다.
- 대화 저장/불러오기 버튼을 제거한다. 사용자 요청과 AI 답변이 추가될 때마다 자동 저장하고, 편집기에 다시 접속하면 자동 복원한다.
- 대화는 계정별 `photo-edit` 대화방 하나로 유지한다. 카드나 콘텐츠를 바꿔도 같은 대화를 이어간다.
- 보관함 콘텐츠 저장과 대화 기록은 독립적이다. 신규 콘텐츠에는 `photoChats`를 넣지 않는다. 기존 프로젝트의 이 필드는 데이터 보존을 위한 호환용으로만 읽고 새 대화에 복사하지 않는다.
- 로그인 사용자는 Supabase `photo_chat_history`에 저장하며 RLS로 계정을 격리한다. 브라우저 캐시는 계정/대화방별로 분리한다. 비회원은 브라우저에 저장한다.
- 저장은 로컬 캐시 우선이며 클라우드 쓰기를 순서대로 처리한다. 실패한 저장은 dirty 상태로 유지하고 10초마다 재시도한다. 재접속 시 미동기화 기록을 먼저 반영한다.
- 클라우드 복원이 실패해도 유효한 로컬 기록이 있으면 표시한다. 인증 계정 불일치에는 다른 계정 캐시를 사용하지 않는다.
- 자동 저장 대상은 사용자 요청과 AI 답변 텍스트다. 참고 이미지와 미적용 수정 후보는 기록에 저장하지 않는다. 수정 사진은 적용 후 콘텐츠를 저장해야 보관된다.
- 최대 메시지 200개이며 한도에 도달하면 기존 기록을 삭제하지 않고 신규 요청을 막는다.

## 입력 및 스크롤

- Enter는 메시지를 전송하고 Shift+Enter는 줄을 바꾼다.
- 한글 조합 중 Enter 및 키 반복 입력은 전송하지 않는다.
- 패널 열기, 기록 복원, 사용자 메시지 전송, AI 응답, 진행/오류 표시 시 대화 스크롤을 맨 아래로 이동한다.
- 이미지가 늦게 로딩되어 영역 높이가 바뀌어도 최신 메시지가 보이도록 맞춘다.

## 원격 사진 변환 오류 수정

- 보관함의 Supabase 원격 사진은 `src` 지정 전에 `crossOrigin = 'anonymous'`로 로딩하여 캔버스 내보내기가 가능하도록 한다.
- 데이터 URL, Blob URL, 앱 내부 사진 경로는 기존 로딩 경로를 유지한다.
- 변환 실패는 사용자용 오류로 처리한다.
- 회귀 검사: 원격 CORS 설정 순서, 로컬 사진 경로 보존, 내보내기 실패 처리, Enter/Shift+Enter/한글 조합/키 반복 검증 포함 총 79개 테스트 통과.

- 공개 사이트 저장된 Supabase 사진으로 Shift+Enter 줄바꿈, Enter 전송, AI 수정 결과 수신 확인. 마지막 스크롤 보정 후 사용량 안내 높이 변경 전후 하단 오차 1px 미만 확인. 최종 배포 `344a6409`, JS `index-CSTAzIK-.js`.

## 채팅창 너비 조절

- 800px보다 넓은 화면에서는 왼쪽 경계 손잡이를 드래그하여 너비를 조절한다. 기본 520px, 최소 320px(작은 화면은 화면 절반), 최대 화면 50%.
- PC에서는 입력 방식 탭과 인물 보관함을 같은 줄에 배치하고, 입력창과
  전송 버튼도 나란히 표시해 대화 영역의 높이를 확보한다.
- 키보드 왼쪽/오른쪽 화살표24px 조절, Home최소/End최대 지원. 창 크기 변경에도50%한도를 유지한다.
- 채팅 폭과 편집영역 오른쪽 여백을 함께 바꾸며, 남은 폭에 따라 미리보기와 입력 폼이2열/1열로 자동배치된다. 닫으면 편집영역이전체폭으로복원된다.
- 실제드래그/최대초과드래그/키보드/닫기검증, 총81테스트와배포검사통과. 공개1900px화면에서채팅950px 및편집영역경계일치확인. 배포68bc86ee.

- 화면 너비 800px 이하에서는 전체 너비의 하단 패널이 아래에서 위로 열린다.
- 패널 높이는 화면의 85%이며 상단 모서리를 둥글게 표시한다.

- 닫기 버튼으로 닫으며, 대화·입력·AI 요청 동작은 기존과 같다.
- 모션 줄이기 설정에서는 슬라이드 애니메이션을 생략한다.
- 튜토리얼 중에는 안내창 위 공간에 채팅 패널을 배치한다.

## 선택 카드와 인물 보관함 접근

- 선택한 카드의 썸네일과 이름을 채팅 제목 아래에 고정한다. 누르면 현재
  문구·레이아웃·브랜드 스타일이 반영된 실제 카드를 크게 확인하고 접을 수 있다.
  편집기와 같은 렌더링 결과를 사용하며, 대화 스크롤과 분리한다.
- 인물 보관함은 입력창 가까이의 버튼으로 열고, 입력창 위에 펼친다.
  긴 목록은 보관함 내부에서 스크롤한다. 이름 변경·삭제·저장 재시도를 유지한다.
- 인물을 선택하면 기존 AI 사진 수정의 참고 이미지에 추가하고 보관함을
  접는다. 참고 이미지 최대 3장 제한으로 추가하지 못하면 보관함을 유지한다.
- 보관함 선택 자체로 카드 사진을 교체하거나 유료 AI 요청을 실행하지 않는다.
- 새 위치를 설명하는 선택 카드·인물 보관함 튜토리얼 단계를 추가한다.

검증 범위: 긴 대화에서 카드/보관함 접근, 카드 사진 확인, 인물 선택과 3장
제한, 보관함/패널 닫기, 이름 변경·삭제, 모바일 하단 패널, 튜토리얼.

## 대화 공간 우선 배치

- 선택 카드와 제목은 얇은 고정 줄로 표시하고, 카드 확대는 대화 위에
  겹쳐 보여 대화 영역의 높이를 줄이지 않는다.
- 입력창과 전송 버튼을 같은 줄에 두고, 사용량은 한 줄로 요약한다.
- 참고 사진과 사용 안내는 접힌 상태로 시작한다. 펼친 상세 영역에서
  사진 추가·용도 변경·삭제와 연결 재확인을 이용할 수 있다.
- 참고 사진과 사용 안내는 Escape로 먼저 접고, 다시 누르면 채팅을 닫는다.
