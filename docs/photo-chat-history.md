# AI 사진 대화 자동 저장

- AI 탭의 A/I를 간격 없는 세로 스택으로 배치한다.
- 대화 저장/불러오기 버튼을 제거한다. 사용자 요청과 AI 답변이 추가될 때마다 자동 저장하고, 편집기에 다시 접속하면 자동 복원한다.
- 대화는 계정별 `photo-edit` 대화방 하나로 유지한다. 카드나 콘텐츠를 바꿔도 같은 대화를 이어간다.
- 보관함 콘텐츠 저장과 대화 기록은 독립적이다. 신규 콘텐츠에는 `photoChats`를 넣지 않는다. 기존 프로젝트의 이 필드는 데이터 보존을 위한 호환용으로만 읽고 새 대화에 복사하지 않는다.
- 로그인 사용자는 Supabase `photo_chat_history`에 저장하며 RLS로 계정을 격리한다. 브라우저 캐시는 계정/대화방별로 분리한다. 비회원은 브라우저에 저장한다.
- 저장은 로컬 캐시 우선이며 클라우드 쓰기를 순서대로 처리한다. 실패한 저장은 dirty 상태로 유지하고 10초마다 재시도한다. 재접속 시 미동기화 기록을 먼저 반영한다.
- 클라우드 복원이 실패해도 유효한 로컬 기록이 있으면 표시한다. 인증 계정 불일치에는 다른 계정 캐시를 사용하지 않는다.
- 자동 저장 대상은 사용자 요청과 AI 답변 텍스트다. 참고 이미지와 미적용 수정 후보는 기록에 저장하지 않는다. 수정 사진은 적용 후 콘텐츠를 저장해야 보관된다.
- 최대 메시지 200개이며 한도에 도달하면 기존 기록을 삭제하지 않고 신규 요청을 막는다.

## 입력 및 스크롤

- Enter는 메시지를 전송하고 Shift+Enter는 줄을 바꾼다.
- 한글 조합 중 Enter 및 키 반복 입력은 전송하지 않는다.
- 패널 열기, 기록 복원, 사용자 메시지 전송, AI 응답, 진행/오류 표시 시 대화 스크롤을 맨 아래로 이동한다.
- 이미지가 늦게 로딩되어 영역 높이가 바뀌어도 최신 메시지가 보이도록 맞춘다.

## 원격 사진 변환 오류 수정

- 보관함의 Supabase 원격 사진은 `src` 지정 전에 `crossOrigin = 'anonymous'`로 로딩하여 캔버스 내보내기가 가능하도록 한다.
- 데이터 URL, Blob URL, 앱 내부 사진 경로는 기존 로딩 경로를 유지한다.
- 변환 실패는 사용자용 오류로 처리한다.
- 회귀 검사: 원격 CORS 설정 순서, 로컬 사진 경로 보존, 내보내기 실패 처리, Enter/Shift+Enter/한글 조합/키 반복 검증 포함 총 79개 테스트 통과.

- 공개 사이트 저장된 Supabase 사진으로 Shift+Enter 줄바꿈, Enter 전송, AI 수정 결과 수신 확인. 마지막 스크롤 보정 후 사용량 안내 높이 변경 전후 하단 오차 1px 미만 확인. 최종 배포 `344a6409`, JS `index-CSTAzIK-.js`.
