# 모아 스튜디오

카페 사진과 메뉴 정보를 카드뉴스 3장, 인스타그램 게시글, 주간 게시 계획으로 만드는 웹 앱입니다. 로컬 서버 방식과 Cloudflare Pages + Supabase 클라우드 방식을 지원합니다.

## 실행

Node.js 22.17 이상을 사용합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 웹 개발 서버와 생성 API 서버가 함께 실행됩니다.

처음에는 사진 중심의 모아 소개 화면이 열립니다. 스크롤하여 소개와 만드는 과정을 보거나 **스튜디오 열기**를 눌러 편집기로 들어갈 수 있습니다. 편집기 주소는 `http://127.0.0.1:5173/#/studio`입니다. 상단 로고로 홈에 돌아올 수 있으며, 같은 세션에서 홈을 왕복해도 작성 중인 내용은 유지됩니다. 새로고침 전에는 보관함에 저장하세요.

## 사용 흐름

1. **브랜드 설정**에서 카페 이름, 한 줄 소개, 위치, 인스타그램 계정, 컬러를 저장합니다.
2. **콘텐츠 만들기**에서 사진을 최대 3장 올립니다. JPG/PNG/WEBP를 지원하며 파일당 최대 10MB입니다.
3. 메뉴 이름, 설명, 가격, 말투, 콘텐츠 목적을 정하고 **콘텐츠 만들기**를 누릅니다.
4. 카드뉴스 3장을 확인하고 문구를 수정합니다. 게시글과 주간 일정도 별도 탭에서 확인합니다.
5. 상단 **저장**으로 보관함에 저장하거나 미리보기의 **PNG** 또는 **ZIP** 버튼으로 다운로드합니다.

현재 전달 버전은 사용자의 선택에 따라 **템플릿 모드**입니다. 문구는 입력한 메뉴 정보·말투·목적을 반영한 규칙 기반 템플릿으로 구성되며, AI가 생성한 것으로 표시하지 않습니다. API 키나 외부 AI 서비스 없이 사용할 수 있습니다.

ZIP에는 1080×1350 PNG 카드뉴스와 게시글·해시태그·게시 계획 텍스트가 포함됩니다. 미리보기와 다운로드는 같은 Canvas 렌더러를 사용합니다.

## 저장 및 데이터

- 비회원의 사진·프로젝트·브랜드는 현재 브라우저의 localStorage에 저장됩니다.
- 회원가입과 로그인은 이메일/비밀번호 방식입니다. 로그인한 계정의 브랜드와 프로젝트는 로컬 모드에서는 SQLite, 클라우드 모드에서는 Supabase PostgreSQL에 저장됩니다. 클라우드 사진은 계정별 비공개 Storage에 보관합니다.
- 로그인·로그아웃 시 해당 계정/비회원 보관함으로 전환됩니다. 전환 전에 편집 내용을 저장하세요. 비회원 보관함을 계정으로 자동 복사하지 않습니다.
- 데이터베이스는 `.data/moa-studio.sqlite`에 생성되며 Git에서 제외됩니다. 이 파일을 보관해야 계정과 콘텐츠를 유지할 수 있습니다.
- 업로드 이미지는 긴 변 1600px 이하 JPEG로 압축합니다. 원본 파일은 변경하지 않습니다.
- 브라우저 데이터를 삭제하면 비회원 보관함도 삭제됩니다. 보관할 결과물은 ZIP으로 내려받으세요.
- 템플릿 생성은 로컬 모드에서는 API 서버, 클라우드 모드에서는 브라우저에서 처리됩니다. 사용자 사진은 외부 AI에 전송되지 않습니다.
- `.env*`는 Git에서 제외합니다. AI API 키는 저장하지 않았으며, 토스 테스트 키는 비공개 `.env.local`에서 읽습니다.

## 구성

- `src/App.tsx`: 프로젝트 상태, 생성 API 연결, 저장과 다운로드 조율
- `src/views/Landing.tsx`, `src/landing.css`: 사진 중심 메인, 스크롤 소개와 시작 흐름
- `src/studio.css`: 상단 내비게이션과 미리보기 중심 편집기 레이아웃
- `src/components/`: 편집 화면, 공통 셸, 결과 탭
- `src/views/`: 보관함, 브랜드 설정
- `src/lib/`: 사진 압축, Canvas 렌더링, ZIP, 브라우저 저장, 계정 API
- `src/views/AuthDialog.tsx`, `src/auth.css`: 로그인·회원가입·계정 창
- `server/auth.mjs`: 비밀번호 해시, 쿠키 세션, 계정별 SQLite 보관함
- `server/`: 입력 검증, 템플릿 생성, 선택적 AI 공급자 연결
- `docs/design/`: 디자인 기준 이미지와 검증 기록

## 검증 명령

```sh
npm run typecheck
npm test
npm run build
```

`npm run preview`는 빌드된 프런트엔드 확인용입니다. Supabase 환경변수로 빌드하면 클라우드 계정·보관함과 브라우저 템플릿 생성이 동작합니다. 로컬 서버 모드는 `npm run dev`로 확인하세요.

## 현재 범위

사진 업로드, 템플릿 콘텐츠 생성, 문구 편집, 게시글 복사, 주간 계획, 브랜드 설정, 보관함, PNG/ZIP 내보내기를 포함합니다. 메인 페이지의 등장·스크롤 모션과 이메일 회원가입·로그인·로그아웃도 포함합니다. 운영체제의 동작 줄이기 설정을 존중합니다.

인증은 로컬 서버 또는 Supabase Auth에서 동작합니다. 클라우드 회원가입은 이메일 확인 절차를 지원하며 일반 고객에게 메일을 보내려면 SMTP 설정이 필요합니다. 비밀번호 재설정 UI, 소셜 로그인, SNS 자동 게시는 포함하지 않습니다. HTTPS에서는 `MOA_SECURE_COOKIES=1`로 Secure 쿠키를 사용하세요. 데이터베이스 경로는 `MOA_DATA_FILE`로 지정할 수 있습니다.

실제 OpenAI 연결용 서버 경로는 분리되어 있습니다. API 연결을 추가할 때는 보안 커넥터 재인증과 별도 생성 검증이 필요합니다. 현재 API 연결은 검증하지 않았습니다.

## 토스페이먼츠

가격표에서 플랜을 선택하여 토스 결제창으로 연결하는 흐름을 구현했습니다. 주문 생성·서버 승인·결과 조회와 테스트/라이브 구분을 포함합니다. 실제 상점 API 키가 없으면 결제는 비활성화됩니다. 자동 정기 청구와 유료 기능 제공은 별도 구현이 필요합니다. 설정 및 검증 범위는 [결제 연결 안내](docs/payments.md)를 참고하세요.

## 운영 배포 준비

`npm run build` 후 `npm start`로 빌드한 웹 화면과 API를 같은 서버에서 제공합니다. 컨테이너·HTTPS·데이터 보존 구성은 [운영 배포 안내](docs/deployment.md)를 참고하세요. 아직 운영 도메인과 서버는 지정하지 않았으며, 로컬 결제는 테스트 모드를 유지합니다.

## 무료 클라우드 구성

Cloudflare Pages + Supabase 배포 설정과 데이터 보존 내용은 [무료 클라우드 배포 안내](docs/cloud-deployment.md)를 참고하세요. 실제 원격 배포 상태도 해당 문서에 기록합니다.
